# Isolated browser checks

Run only against the labelled synthetic Jury staging environment, never a school production database. Scripts require Playwright Chromium, `/runtime/node_modules/playwright`, credential-file mount `/qa/synthetic-secrets.json`, non-secret seed/result mounts `/fixtures` and writable `/results`. The test runner reaches isolated aliases `jury_api`, `jury_nexus_qa`, `edupay_qa`, `jury_kitchen_web`, plus the authorized HTTPS staging host. No credential values are checked in.

`checks.cjs` covers the centered600-session dialog, authenticated SSO, footer-QR teaching documents, scoped SW and offline public shell. `reliability.cjs` covers actual autosave/Ctrl+S, encrypted offline drafts, lost response after commit, idempotent reconnect and responsive scoring. `sso-intent.cjs` proves explicit account confirmation/cancellation/switching. `guide-captures.cjs` exercises seven institutional roles. `visual-checks.cjs` and `lot-visual.cjs` capture real components in both themes and 320/390/820/1440 widths; the latter intentionally uses read-only synthetic DTOs for Kitchen/EduPay layout, not business verification. `download-tests.cjs` exercises the actual authenticated document-download endpoint.

Fixtures are not an automatic production deployment. Database-oriented CJS fixtures reject a database URL outside the dedicated `jury_db:5432/jury_stage` environment before constructing Prisma. File-regression runners additionally mount the own private-files volume read-only at `/jury-private` to compare directory entries. Native OS installation/link-capture still needs a real school-device acceptance check.
